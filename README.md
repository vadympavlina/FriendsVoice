# Friends Voice

Голосовий чат для друзів у стилі Discord, але без сервера. Нативна Windows-програма на **Rust + egui**: голос, камера й текстовий чат ідуть напряму між комп'ютерами 2–5 друзів у спільній **приватній мережі Radmin VPN**.

## Як почати
1. Усі встановлюють Radmin VPN і заходять в одну довірену мережу.
2. Завантаж `FriendsVoice-Windows-x64.zip` з [Releases](https://github.com/vadympavlina/FriendsVoice/releases), розпакуй і запусти `friends-voice.exe`.
3. Друзі знаходять одне одного автоматично. Якщо ні, у лівій панелі натисни «Додати друга за IP» і введи його адресу `26.x.x.x`.
4. Клікни канал «Загальний» або кнопку «Приєднатися до голосу».

Потрібні UDP-порти лише всередині VPN: 45888 (виявлення й чат), 45889 (голос), 45890 (камера). Не відкривай їх в інтернет.

## Інтерфейс
Три зони, як у знайомих голосових клієнтах:
- **Ліворуч:** канал «Загальний» з учасниками голосу під ним, список друзів у мережі, твоя VPN-адреса з копіюванням, панель користувача (мікрофон, звук, налаштування).
- **Посередині:** сцена з плитками учасників. Той, хто говорить, підсвічується зеленою рамкою. Знизу керування дзвінком.
- **Праворуч:** чат із пошуком. Однакові службові повідомлення згортаються в одне («×3»).

Налаштування відкриваються окремою сторінкою: Звук, Відео, Загальні, Про програму.

| Клавіша | Дія |
|---|---|
| Ctrl+M | мікрофон |
| Ctrl+B | бічна панель |
| Ctrl+E | театральний режим (без чату, плитки на всю сцену) |
| Ctrl+F | пошук у чаті |
| Esc | закрити пошук, налаштування чи театральний режим |
| F9 | мікрофон з будь-якого вікна |
| F8 (за замовчуванням) | Push-to-Talk. Клавішу можна змінити на будь-яку: Налаштування → Звук → «Змінити клавішу» (літери, F-клавіші, Num, Shift/Ctrl/Alt, бічні кнопки миші) |

## Камера
- Камери показуються за справжніми назвами; у Налаштуваннях → Відео є **перегляд камери** ще до входу в дзвінок. Поки ти не в голосовому каналі, друзі цей перегляд не отримують, а камера вимикається, щойно ти залишаєш сторінку.
- Кадр обрізається до 16:9 по центру (без розтягування), свій перегляд дзеркальний, друзям іде нормальне зображення.
- Якщо камера не віддає MJPEG, програма пробує YUY2/NV12 та інші формати.
- Чотири якості: Економія 320×180, Баланс 480×270, Висока 640×360, HD 960×540 (до ≈6 Мбіт/с на кожного друга). Передача: JPEG через UDP із відновленням одного втраченого пакета.
- У налаштуваннях видно режим камери й лічильники кадрів, тож «мовчазну» камеру легко діагностувати.

## Обмеження
Власного наскрізного шифрування та перевірки особи друга немає, захист дає лише приватна VPN-мережа. Демонстрація екрана й усунення луни не реалізовані. Історія чату зберігається лише до закриття програми.

## Збірка
```bash
cargo test
cargo build --release
```
Реліз збирає GitHub Actions (`.github/workflows/windows-release.yml`): архів із `friends-voice.exe` з'являється в Releases.
