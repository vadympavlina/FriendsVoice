# Friends Voice

[English](README.md) · [Українська](README.uk.md) · **Русский**

Голосовой чат для друзей в стиле Discord, но без сервера. Нативная Windows-программа на **Rust + egui**: голос, камера, показ экрана и текстовый чат идут напрямую между компьютерами 2–5 друзей в общей **частной сети Radmin VPN**.

## Как начать
1. Все устанавливают Radmin VPN и заходят в одну доверенную сеть.
2. Скачай `FriendsVoice-Windows-x64.zip` из [Releases](https://github.com/vadympavlina/FriendsVoice/releases), распакуй и запусти `friends-voice.exe`.
3. Друзья находят друг друга сами. Если нет, нажми в левой панели «Добавить друга по адресу» и введи его адрес `26.x.x.x`.
4. Нажми канал «Общий» или кнопку «Присоединиться к голосу».

UDP-порты нужны только внутри VPN: 45888 (поиск и чат), 45889 (голос), 45890 (JPEG-камера), 45891 (H.264: HD-камера и показ экрана). Не открывай их в интернет.

## Языки
English (по умолчанию), Українська и Русский. Переключение: Настройки → Профиль или стартовый экран, меняется сразу.

## Возможности
- **Камера:** до **1920×1080 при 30 к/с** (H.264), предпросмотр в настройках до входа в звонок виден только тебе.
- **Показ экрана:** весь экран или одно окно, 720p–4K, 15/30/60 к/с, оценка трафика перед стартом. Звук компьютера пока не передаётся.
- **Развернуть на всё окно или весь экран:** кнопки на плитке, двойной клик, **F11**. В развёрнутом виде колесо мыши увеличивает до 600%, перетаскивание двигает картинку, **Esc** возвращает назад.
- **Звуки:** отдельные сигналы для микрофона, звука, камеры, показа экрана, твоего входа и выхода и особый «колокольчик», когда заходит друг.
- **Чат:** кликабельные ссылки, поиск (Ctrl+F), тихий сигнал и мигание кнопки на панели задач, если окно в фоне.
- **Push-to-Talk:** любая клавиша или кнопка мыши (Настройки → Звук).
- **Удобство:** масштаб интерфейса 90–150%, запоминание размера окна, «Скопировать отчёт» в разделе «О программе» и журнал сбоев в `%APPDATA%\FriendsVoice\crash.log`.

## Ограничения
Сквозного шифрования и проверки личности нет, защищает только частная VPN-сеть. Подавление эха не реализовано. История чата хранится только до закрытия программы.

## Сборка
```bash
cargo test
cargo build --release
```
Релиз собирает GitHub Actions: после слияния в `main` архив с `friends-voice.exe` появляется в Releases.
